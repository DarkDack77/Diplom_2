# Diplom_2 — API-тесты Stellar Burgers

Часть дипломного проекта по программе «Инженер по тестированию: от новичка до автоматизатора» (Яндекс Практикум).

Автоматизированные тесты для API учебного сервиса Stellar Burgers: регистрация и авторизация пользователей, создание заказов.

## Что покрыто тестами

- Регистрация пользователя: успешная регистрация, попытка зарегистрировать уже существующего пользователя, регистрация без обязательных полей (email, пароль, имя)
- Авторизация: вход с верными и неверными данными
- Создание заказа: с ингредиентами и без, с валидным и невалидным токеном авторизации

**Итого: 14 тестов, все проходят успешно.**

## Технологии

- Java 11
- REST Assured — отправка запросов и проверка ответов API
- JUnit 4
- Allure — отчётность по результатам тестирования
- Maven

## Как запустить

```
mvn clean test
mvn allure:serve
```

Вторая команда откроет интерактивный Allure-отчёт в браузере с деталями каждого теста.

## Особенности реализации

- Тестовые данные генерируются с уникальным email (UUID), чтобы тесты не конфликтовали друг с другом при повторных запусках
- Код прошёл ревью наставника: скорректированы ожидаемые коды ответа API, добавлена отчётность Allure
